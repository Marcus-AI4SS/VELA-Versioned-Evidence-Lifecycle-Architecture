# VELA Runtime Notes

This directory is part of the public VELA package.

When editing it:

- Keep content product-facing and reusable.
- Do not add machine-specific paths, credentials, browser state, account data, generated outputs, or private project notes.
- Prefer schemas, validators, and tests for behavior that other users should rely on.
- Keep optional integrations explicit; VELA should check or guide them, not silently copy user runtime state.
