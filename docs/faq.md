# FAQ

## Is VELA an app?

No. VELA is a workflow package for Codex projects. It installs files, commands, schemas, validators, and runtime helpers into your own environment.

## Does VELA write my paper?

No. VELA helps keep the research path inspectable. Codex can help with bounded tasks, but claims and evidence still need review.

## Can I use my own project structure?

Yes. Keep the core distinctions: materials, evidence, claims, methods, deliverables, handoffs, and logs.

## Can I use Zotero, Obsidian, Python, R, or notebooks?

Yes. VELA records how those tools connect to the project state; it does not replace them or copy private databases.
