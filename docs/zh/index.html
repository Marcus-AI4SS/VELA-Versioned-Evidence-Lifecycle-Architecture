VELA
English 简体中文
Versioned Evidence Lifecycle Architecture

VELA

面向 Codex 研究项目的便携式工作流包：项目结构、交接提示、证据台账、验证、隐私扫描和 HELM 可读状态。

以工程控制论为底层方法：目标、状态、反馈、验证和校正都落在文件里。

开始 安装 交接契约 连接 HELM

VELA 提供什么

让 Codex 在清楚的项目边界里工作，而不是依赖零散聊天记录。

项目结构

materials、evidence、claims、methods、deliverables、handoffs、logs。

Codex 规则

AGENTS.md 和命令模板让任务范围可读、可复核。

证据生命周期

材料、证据、主张和交付物分层管理。

控制循环

目标、状态、反馈信号、验证门和校正动作都保存在项目文件中。

安装

Windows

git clone https://github.com/Marcus-AI4SS/VELA.git vela
cd vela
.\install.ps1 -BootstrapTools

macOS

git clone https://github.com/Marcus-AI4SS/VELA.git vela
cd vela
sh ./install-macos.sh

Linux / shell

git clone https://github.com/Marcus-AI4SS/VELA.git vela
cd vela
sh ./install.sh --bootstrap-tools

使用

1. 初始化

vela init my-project 创建项目结构和 .vela/context.json。

2. 交给 Codex

创建、检查并渲染一个有边界的 Codex 任务。

3. 验证

分享前运行项目验证和隐私扫描。

可选组合

VELA 和 HELM 是两个独立工具，通过显式文件接口协作。

VELA 工作流包

创建并验证可携带的研究项目状态。

HELM 本地研究看板

读取项目状态，并帮助准备 Codex 交接。

VELA = Versioned Evidence Lifecycle Architecture。
