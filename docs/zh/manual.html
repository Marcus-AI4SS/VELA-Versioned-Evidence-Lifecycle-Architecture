VELA 说明书

VELA 是面向 Codex 研究项目的便携式工作流包。它把目标、状态、反馈、验证、校正、记忆和演化沉淀为可审查的项目文件。

安装 快速开始 Markdown

VELA 是什么

给 Codex 研究项目使用的文件化工作流包：目录、规则、交接、证据、检查和运行日志。

VELA 不是什么

不是桌面 app、论文生成器、文献管理器、后台自动化服务，也不替代用户自己的工具和数据。

底层逻辑

工程控制论：目标、状态、反馈、验证和校正都必须体现在文件、检查结果和版本历史中。

七层结构

VELA 把研究工作拆开，避免工具、证据、日志、检查和长期规则混成不可审查的黑箱。

层级作用
01 任务与边界明确研究目标、可动范围、约束和验收标准。
02 工具与接口接入 Git、Python、MCP、agentmemory、CodeGraph、Zotero、Obsidian 等用户自有工具。
03 上下文与证据区分材料、证据、主张、方法和交付物。
04 研究阶段组织研究设计、文献、阅读、写作、图表和复盘。
05 运行日志记录操作、失败、检查和修复。
06 可靠性检查运行 schema、validator、测试、隐私扫描和 handoff lint。
07 环境治理决定哪些规则可以通过版本提交长期保留。

安装

VELA 通常形成两层：clone 下来的源包，以及安装到用户 ~/.vela 和 ~/.codex 的本机运行层。

Windows

git clone https://github.com/Marcus-AI4SS/VELA.git vela
cd vela
.\install.ps1 -BootstrapTools
.\vela.ps1 doctor

macOS

git clone https://github.com/Marcus-AI4SS/VELA.git vela
cd vela
sh ./install-macos.sh
~/.vela/bin/vela doctor

Linux / shell

git clone https://github.com/Marcus-AI4SS/VELA.git vela
cd vela
sh ./install.sh --bootstrap-tools
vela doctor

常用命令

目的命令
查看环境状态vela doctor
初始化项目vela init <project>
创建 handoffvela handoff new --template claim-check
检查 handoffvela handoff lint handoffs/H001.yaml
渲染 Codex promptvela handoff render handoffs/H001.yaml --out handoffs/H001.prompt.md
验证项目vela validate <project> --repair-context
隐私扫描vela privacy scan <project>

记忆边界

  • 运行日志、handoff、证据台账和工具反馈进入候选线索。
  • agentmemory 可以召回偏好和历史经验。
  • 记忆不能单独成为源规则。

演化边界

  • 长期规则必须经过 schema、validator、测试、复核和提交。
  • VELA 不复制浏览器登录态、cookies、凭据、私有文献库或用户数据。
  • doctor 会区分已安装、缺失、可选和需要用户配置的工具。
